# Usahana flow settings for <project>

Open a topic file only when a step needs it.

| Topic file | Read it when |
| --- | --- |
| `old-system.md` | Preflight question 1, or you write a spec for a feature from the old system |
| `migrations.md` | Preflight question 5, or the work touches the database schema |
| `issues.md` | You read or update an issue |
| `screens.md` | Preflight question 4, or the work changes UI |
| `incidents.md` | You trace a bug after a merge, or you change a Preflight question |

Delete a row if the project does not need that topic.
